# Create An Asset

Read [the workflow contract](../../references/operating-contract.md) before execution. For this workflow, also read [knowledge and coaching](../../references/knowledge-and-coaching.md), [review actions](../../references/review-actions.md).

Resolve audience, purpose and desired format. Retrieve customer goals plus approved product, case-study and commercial information. Inspect a matching document template before generating saved content.

Create the requested document using `writeDocument` or the specific Library tool, preserving sources and marking unsupported values as questions to validate. Do not fabricate ROI, customer logos, approvals or success metrics.

If slides/PDF or another format needs a separate artifact tool, use it only when available and authorized; otherwise return the supported document with the format limitation. Saving does not publish or send. Prepare a requested delivery email through the card without inventing attachment support.
