# Competitive Intelligence

Read [the workflow contract](references/operating-contract.md) before execution. For this workflow, also read [knowledge and coaching](references/knowledge-and-coaching.md), [review actions](references/review-actions.md).

For a named deal combine its actual competitive statements with approved positioning and sourced public research. For a portfolio question define the cohort and retrieve tracker-backed conversations plus verified deal outcomes.

Separate mentions from competitive deals and account counts from quote counts. Return where the competitor fits, customer-specific differentiation, unresolved gaps and practical responses. State sample sizes and unknown outcomes before discussing win/loss patterns.

Save requested competitor profiles/battlecards with actual competitor/template IDs and cited sources. For ongoing detection use a scoped competition tracker; for an immediate response prepare an email card.
