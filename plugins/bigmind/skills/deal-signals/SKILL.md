# Deal Signals

Read [the workflow contract](../../references/operating-contract.md) before execution. For this workflow, also read [pipeline and frameworks](../../references/pipeline-and-frameworks.md), [review actions](../../references/review-actions.md), [knowledge and coaching](../../references/knowledge-and-coaching.md).

Resolve the requested pipeline/account scope and time window. Read warnings and relevant existing signals; inspect `describeSignalById` for evidence and meaning where needed. Use dated activity to confirm changes and deal relevance.

Return each finding's source/time, affected deal, urgency and specific next action. Avoid presenting a repeated old warning as a new event. Prepare requested outreach, tasks or opportunity reviews.

If the user asks for ongoing detection, use the configuration workflow and verify resulting tracker/automation state. A one-time signal review does not enable monitoring.
