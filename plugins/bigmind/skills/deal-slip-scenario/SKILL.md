# Deal Slip Scenario

Read [the workflow contract](../../references/operating-contract.md) before execution. For this workflow, also read [pipeline and frameworks](../../references/pipeline-and-frameworks.md), [review actions](../../references/review-actions.md).

Establish the baseline with the same period, currency and category mapping used in the forecast. Read the selected deal's actual amount and bucket. Apply the user's scenario as a hypothetical, leaving records unchanged.

Show before/after totals and deltas. If quota is absent, calculate the supported revenue delta and ask for quota only when needed for attainment/coverage. Identify possible replacement deals using actual qualification and timing evidence, not optimistic probability adjustments.

If the user separately asks to apply a change, prepare the opportunity review card and keep the hypothetical result distinct from saved CRM state.
