# Deal Advance Gap

Read [the workflow contract](references/operating-contract.md) before execution. For this workflow, also read [pipeline and frameworks](references/pipeline-and-frameworks.md), [review actions](references/review-actions.md).

Resolve the deal, current framework findings and real stage exit criteria from available configuration or approved playbooks. If criteria are unavailable, label proposed criteria instead of claiming they are company policy.

Map each blocking requirement to evidence, done/in-progress/unknown state, dependency and next action. Separate customer commitments from suggested owners/dates. Identify the action that unblocks the most work; calculate a credible timing range only with supported durations.

Create requested tasks, prepare necessary outreach, save findings and review supported stage/date changes. Do not infer stage-transition history from current stage alone.
