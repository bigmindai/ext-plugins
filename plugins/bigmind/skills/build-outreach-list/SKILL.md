# Build Outreach List

Read [the workflow contract](../../references/operating-contract.md) before execution. For this workflow, also read [campaigns](../../references/campaigns.md).

Resolve audience criteria, exclusions, destination and research depth. Inspect existing Lists before modification; for a new account audience use the account-outreach template. Preview imports, map actual columns and deduplicate verified domains/people.

Use connected enrichment and source-backed research within scope. Persist qualification, account thesis, targetable people and contactability gaps using the dedicated tools. Verify row/person counts and skipped records.

For requested outreach continue into draft-outreach or manage-campaign with the resolved List and people; List creation alone neither enrolls nor sends anything.
