# Stakeholder Map

Read [the workflow contract](../../references/operating-contract.md) before execution. For this workflow, also read [pipeline and frameworks](../../references/pipeline-and-frameworks.md), [review actions](../../references/review-actions.md).

Use `listAccountContacts`, meeting participants and attributed activity to build the known people set. For a deal, distinguish account contacts from people evidenced in that deal. Read applicable qualification requirements where available.

For each person show verified title, evidenced role, recent engagement, stance and sources. Champion status requires demonstrated help, not a favorable comment or title alone. Identify missing roles, single-thread risk and verified introduction paths; never invent reporting lines or mutual connections.

Return the map and next relationship action. Prepare requested introduction/follow-up email via the card or create a task. Only create contacts if an actual exposed tool supports it.
